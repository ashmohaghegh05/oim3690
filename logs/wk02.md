# Week 2

## What I worked on

This week I spent more time working directly with HTML and Markdown.

Instead of only looking at the final webpage, I started reading the HTML that produced it.

I looked at AI-generated HTML and tried to identify which parts I already understood and which parts I needed to investigate further.

I also learned more about the difference between using AI as a chat tool and using an AI coding tool that can work with files inside a project.

## What gave me trouble

Reading the code was harder than simply asking AI to generate a webpage.

Some parts of an HTML document were less obvious at first, including:

- `<!DOCTYPE html>`
- `<meta charset="UTF-8">`
- the viewport meta tag
- semantic elements such as `<header>` and `<section>`
- relative links such as `href="index.html"`

This made me realize that seeing a page work in the browser does not automatically mean that I understand the code behind it.

## Something new I learned

I learned that HTML gives structure and meaning to a webpage.

The `<head>` contains information about the document, while the `<body>` contains the content that visitors see.

I also learned that:

- `<ul>` creates an unordered list.
- `<ol>` creates an ordered list.
- `<li>` represents each list item.

I learned that HTML attributes give additional information about an element.

For example:

`<a href="index.html">Home</a>`

uses the `<a>` element to create a link, while `href` tells the browser where the link should go.

## What I Learned From Reading `hello.html`

One of the most useful things I learned from reading the AI-generated `hello.html` was how semantic HTML describes the structure of a webpage.

I noticed these elements:

- `<header>`
- `<main>`
- `<section>`
- `<footer>`

I learned that they describe different parts of the page.

For example:

- `<header>` introduces the page.
- `<main>` contains the primary content.
- `<section>` groups related content.
- `<footer>` contains ending or supporting information.

I also learned something from this line:

`<a href="index.html">Return to my OIM3690 homepage</a>`

Because `hello.html` and `index.html` are in the same folder, the browser can use the relative path `index.html` instead of requiring the full website address.

## Working with AI

The biggest thing I noticed this week is that generating code and understanding code are different activities.

AI can produce a complete HTML file extremely quickly, but reading that file requires me to slow down and ask questions.

I found that asking questions such as:

- What does this element do?
- Why is this attribute here?
- What happens if I remove this line?
- Is there a simpler way to write this?

helps me understand the generated code instead of simply accepting it.
