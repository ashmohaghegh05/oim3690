## Something New I Learned

I learned that arrays are useful when I need to store a list of related values.

Each item in an array has an index, starting with `0`, so the first item is at index `0`, the second item is at index `1`, and so on.

I also learned that loops make it possible to repeat the same action for every item in an array instead of writing the same code many times.

For example, in the Playlist exercise, the loop goes through the array of songs, creates a list item for each song, and adds it to the page.

I also learned about common things we can do with arrays, such as filtering, searching, counting, and calculating totals. These same patterns can be used in many different web applications.
