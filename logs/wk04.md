# Week 4

## What I worked on

- This week I continued working with CSS and focused more on layout and responsive design.
- I learned that a webpage should not only look good on my laptop but should also work well on smaller screens.
- I also practiced reading AI-generated code and thinking more carefully about how to debug problems instead of immediately asking AI to rewrite everything.

## What gave me trouble / where I am still stuck

- CSS layout is harder for me than simply changing colors or fonts because several rules can affect the position of an element.
- I am still learning how to predict how a page will behave at different screen sizes.
- I also need more practice using browser DevTools to identify exactly which CSS rule is creating a problem.

## Something new I learned

- I learned that responsive design allows a webpage to adapt to different screen sizes.
- I learned that media queries can apply different CSS rules depending on the width of the screen.
- I also learned that DevTools can help inspect an element and show the CSS rules affecting it.

## Working with AI

- I noticed that debugging with AI works better when I describe the exact problem.
- Saying “the page looks wrong” is much less useful than explaining which element is wrong, what I expected, and what actually happened.
- I also learned that I should check AI's suggested fix myself instead of assuming it is correct.
