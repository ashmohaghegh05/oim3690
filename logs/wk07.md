I also had to think carefully about the order of `if` and `else if` statements. I learned that even if every condition looks correct individually, putting them in the wrong order can cause JavaScript to return the wrong result.

Another thing I found difficult was reading shorter versions of JavaScript conditions. Sometimes AI writes a condition in a very compact way, and it takes me longer to understand what it actually means.

## Something New I Learned

I learned that JavaScript checks an `if / else if / else` structure from top to bottom.

Once it finds a condition that is true, it runs that block and does not continue checking the remaining branches.

I also learned more about logical operators:

- `&&` means both conditions need to be true.
- `||` means at least one of the conditions needs to be true.

The Member Discount example helped me understand how functions and conditionals work together. A function can receive values as parameters, check conditions using those values, and then `return` a result.

I also learned that understanding business rules before writing code is important. If the rule itself is written incorrectly, the JavaScript may work exactly as written but still give the wrong answer.
