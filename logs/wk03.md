# Week 3

## What I worked on

- I created and styled my `about-me.html` page.
- I practiced adding CSS inside a `<style>` block in the `<head>`.
- I experimented with colors, fonts, spacing, headings, and links.
- I also learned more about semantic HTML such as `<header>`, `<nav>`, `<main>`, `<section>`, and `<footer>`.

## What gave me trouble / where I am still stuck

- I was initially confused about how CSS selectors connect to HTML.
- I am still getting used to deciding when I should use an element selector such as `h1` and when I should use a class.
- Relative file paths are also something I need to pay attention to when files are moved into different folders.

## Something new I learned

- I learned that CSS can be written inline, inside a `<style>` block, or in an external stylesheet.
- I learned that a class can be reused across multiple elements.
- I learned that if two CSS rules have the same priority, the later rule can override the earlier one.
- I also learned that colors can be represented using names, RGB values, or hexadecimal values.

## Working with AI

- I noticed that AI can generate CSS very quickly, but the first design can look generic.
- I found it more useful to tell AI exactly what I wanted changed instead of simply asking it to “make the page look better.”
- I changed parts of the styling so that the page reflected my own choices rather than keeping the first AI-generated version.
