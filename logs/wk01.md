# Week 1

## What I worked on

This week I learned how GitHub can be used to store and publish a website. I worked with repositories, HTML files, and GitHub Pages.

## What gave me trouble

One thing I found confusing at first was the difference between saving, committing, and pushing changes.

I learned that saving changes the file, committing records a version of the work, and pushing sends those commits to GitHub.

## Something new I learned

I learned that `index.html` is normally the default page loaded by a browser when visiting a website.

I also learned that GitHub Pages can publish files from a GitHub repository as a public website.
