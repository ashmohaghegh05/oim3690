## Predict Before You Delete

I tested three parts of my own `js/todo.js` file. Before removing each one, I predicted what would happen. Then I temporarily removed the code, tested the To-Do app, and restored the code before moving to the next test.

### Test 1 — Event Listener

Code:

```javascript
form.addEventListener("submit", function(event) {
```

**Prediction before deleting:**  
I predicted that if I removed the form submit event listener, clicking the Add button would no longer run the JavaScript that adds a new task.

**What happened after deleting it:**  
When I removed the event listener and tried to add a task, the JavaScript that normally adds the task did not run, so the new task did not appear in the To-Do list.

**Was my prediction correct?**  
Yes.

**What I learned:**  
I learned that `addEventListener()` connects a user action, such as submitting a form, to the JavaScript that should run.

---

### Test 2 — Line That Changes the Page

Code:

```javascript
list.innerHTML = "";
```

**Prediction before deleting:**  
I predicted that if I removed this line, the old tasks would not be cleared before `render()` created the task list again. I thought this would cause duplicate tasks to appear.

**What happened after deleting it:**  
When I removed the line and `render()` ran again, the old task elements stayed on the page. JavaScript then added the tasks again, so duplicate tasks appeared.

**Was my prediction correct?**  
Yes.

**What I learned:**  
I learned that `list.innerHTML = "";` clears the visible task list before `render()` rebuilds it. The task data is still stored in the `todos` array.

---

### Test 3 — A Choice in the Code

Code:

```javascript
if (currentFilter === "done" && !todo.completed) return;
```

**Prediction before deleting:**  
I predicted that if I removed this condition, unfinished tasks would also appear when I selected the Done filter.

**What happened after deleting it:**  
When I removed the condition and selected Done, unfinished tasks also appeared. The Done filter no longer showed only completed tasks.

**Was my prediction correct?**  
Yes.

**What I learned:**  
I learned that this `if` statement controls which tasks are shown. When the filter is set to `done`, unfinished tasks are skipped using `return`.

---

### Overall Result

All three of my predictions were correct.

This exercise helped me understand that:

- `addEventListener()` connects user actions to JavaScript.
- `list.innerHTML = "";` clears the old page content before the list is rebuilt.
- `if` conditions control which tasks are shown or hidden.

Removing one piece of code at a time helped me understand what each part of the To-Do app was responsible for.
