## Changes I Made to the JavaScript

I made several changes to my To-Do app JavaScript this week.

The biggest change was adding **All / Open / Done filters**.

I added:

```javascript
const filterButtons = document.querySelectorAll("#filter-buttons button");
```

This lets JavaScript find the filter buttons on the page.

I also added:

```javascript
let currentFilter = "all";
```

This keeps track of which filter is currently selected.

Inside the `render()` function, I added:

```javascript
if (currentFilter === "open" && todo.completed) return;
if (currentFilter === "done" && !todo.completed) return;
```

These conditions decide which tasks should appear.

- **All** shows every task.
- **Open** shows only unfinished tasks.
- **Done** shows only completed tasks.

I also added click event listeners to the filter buttons:

```javascript
filterButtons.forEach(function(button) {
    button.addEventListener("click", function() {
        currentFilter = button.dataset.filter;

        filterButtons.forEach(function(otherButton) {
            otherButton.classList.remove("active-filter");
        });

        button.classList.add("active-filter");

        render();
    });
});
```

This changes the selected filter and runs `render()` again.

I also updated the empty message so the app can show:

- `No tasks yet.`
- `No open tasks.`
- `No completed tasks.`

The To-Do app also uses JavaScript to:

- Add new tasks.
- Mark tasks complete using checkboxes.
- Delete tasks.
- Save tasks using `localStorage`.
- Read saved tasks using `JSON.parse()`.
- Save task data using `JSON.stringify()`.
- Rebuild the visible list using `render()`.

I also created a Celsius-to-Fahrenheit converter.

I used this function:

```javascript
function toFahrenheit(celsius) {
    return (celsius * 9 / 5) + 32;
}
```

The function takes a Celsius value and returns the Fahrenheit value.

I then used JavaScript to display the result on the webpage.

## Predict Before You Delete

I chose three pieces of code from my own `js/todo.js` file.

For each test, I predicted what would happen before deleting the code, temporarily removed it, tested the To-Do app, and then restored the original code.

### Test 1 — Event Listener

Code:

```javascript
form.addEventListener("submit", function(event) {
```

**Prediction:**  
If I remove the form submit event listener, clicking the Add button will no longer run the JavaScript that adds a task.

**What happened:**

**Was my prediction correct?**  
Yes.

**What I learned:**
