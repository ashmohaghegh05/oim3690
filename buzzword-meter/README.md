# Buzzword Meter

A Chrome extension for job seekers that counts selected buzzwords on job postings at Lever.

## What it will do

On a Lever job posting, the extension will read the visible job description, count selected terms, and show the counts in a small panel. The first version will use a short, clearly listed set of terms.

## Supported pages

The extension is intended to run on individual job postings on `jobs.lever.co`. It should not run on unrelated websites.
